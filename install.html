홈 화면에 이남노트 두기

한 번 두면 앱처럼 아이콘을 눌러 바로 열려요. 가입이나 앱 장터 설치는 필요 없고, 용량도 거의 차지하지 않아요.

홈 화면에 이 아이콘이 생겨요. 열면 주소창 없이 화면 가득 이남노트가 보여요.

휴대폰별 방법

아이폰 · Safari
  1. 화면 아래(또는 위)의 공유 버튼을 눌러요. 안 보이면 ⋯을 먼저 누르면 나와요.
  2. 목록을 내려 홈 화면에 추가를 눌러요.
  3. 오른쪽 위 추가를 누르면 끝이에요.
아이폰 · Chrome
  1. 주소창 오른쪽의 공유 버튼을 눌러요.
  2. 홈 화면에 추가를 누르고 추가를 눌러요.
  3. 목록에 없으면 iOS가 오래된 것이에요(16.4 이상 필요). Safari에서 해 주세요.
안드로이드 · Chrome
  1. 오른쪽 위 ⋮(점 세 개)를 눌러요.
  2. 홈 화면에 추가 또는 앱 설치를 눌러요.
  3. 설치(또는 추가)를 누르면 끝이에요.
갤럭시 · 삼성 인터넷
  1. 아래 ≡(메뉴)를 눌러요.
  2. 현재 페이지 추가(또는 페이지 추가) → 홈 화면을 눌러요.
  3. 추가를 누르면 끝이에요. 주소창에 설치 아이콘이 보이면 그걸 눌러도 돼요.
카카오톡·네이버 앱에서 열었을 때
  1. 앱 안 화면에서는 홈 화면에 둘 수 없어요. 먼저 다른 브라우저로 열기를 해야 해요.
  2. 화면 구석의 ⋮ 또는 ⋯(공유) 메뉴에서 다른 브라우저로 열기(아이폰은 Safari로 열기)를 눌러요.
  3. 열린 Safari·Chrome에서 위 방법대로 하면 돼요.
PC · Chrome·Edge
  1. 주소창 오른쪽 끝의 설치 아이콘(모니터에 화살표)을 눌러요.
  2. 설치를 누르면 이남노트가 따로 창으로 열려요.

알아 두면 좋은 것

  • 홈 화면에서 열어도 같은 이남노트예요. 열 때마다 새 소식·혜택·날씨를 받아요.
  • 인터넷이 끊겨도 한 번 본 화면은 열려요. 그때 받아 둔 내용이라 지난 정보일 수 있어요.
  • 지우고 싶으면 아이콘을 길게 눌러 삭제하면 돼요. 가입이 없어 따로 지울 계정도 없어요.
  • 앱 장터에 올린 앱이 아니라 홈 화면에 둔 바로가기예요. 이남노트는 용인시·LH·삼성전자의 공식 앱이 아니에요.
이 사이트는 용인시·LH·삼성전자와 무관한 민간 지역 정보 사이트입니다.
